Figure Tools

This is a figure-making tool for building clean, publication-style scientific diagrams — set everything manually and export as SVG.

Tool 1

Timeline Diagram

Study/trial timelines with a custom scale, an optional compressed break, colored highlight regions, and labeled vertical event markers.
Tool 2

Protein Domain Map

Domain/structure organization diagrams: pick residue ranges, per-domain fill/outline/dash styling, label placement and orientation, or randomize with one click.
Tool 3

Analysis Plots

Violin, density, and line plots for your data: paste or upload CSV/Excel, style every series, add region annotations, and control fonts, ticks, and legends.
Tool 4

Multi-Panel Layout

Combine several datasets into one A4 figure: a violin+density grid from multiple files, or several line plots stacked vertically with shared or per-plot formatting.
